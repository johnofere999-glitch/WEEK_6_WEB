 Improvements Made This Week
- Added JavaScript to make the website interactive.
- Added an expense form for entering expense details.
- Added a dashboard that updates automatically.

 Conditionals
- Conditionals check whether spending is within the budget, approaching the limit, or over budget.
- They also validate the information entered by the user.

Arrays
- An array is used to store multiple expense records.
- Each record contains the expense name, amount, and category.

DOM Updates
- JavaScript updates the total expenses, number of expenses, budget status, and expense list on the webpage.

Events
- An event listener detects when the expense form is submitted.
- The user's information is then processed and displayed.

Challenges and Solutions
- A challenge was connecting the form to the dashboard.
- I solved this using event listeners, arrays, loops, and DOM manipulation.
